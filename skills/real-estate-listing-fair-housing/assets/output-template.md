## Notes on the report column

- **Flagged phrase** — quote it exactly as the agent wrote it, so they can find it with ctrl-F.
- **Protected class at risk** — name the class and give a one-line reason. "Familial status — an ordinary reader could read a preference for households with children."
- **Suggested rewrite** — always offer one. A flag without an alternative is just a problem handed back.
